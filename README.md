# flutter_laboratornaya_1

Описание:
Простой Flutter-проект, демонстрирующий создание базового пользовательского интерфейса с использованием виджетов `Container`, `Row`, `Column`, `Text`, `Expanded`, `Scaffold`, `CircleAvatar` и `FloatingActionButton`. Основная цель — знакомство с Flutter. Создание базового UI.

# Как запустить

1. Клонируйте репозиторий:
git clone https://github.com/dissimilate-a/flutterLaboratornaya1
2. Перейдите в папку проекта
3. Запустите приложение на эмуляторе или устройстве:
  * Зайдите в VS Code
  * Убедитесь, что установлен Flutter SDK и выполнена настройка среды (например, выполните команду `flutter doctor`).
  * Убедитесь, что в нижней панели VS Code выбран эмулятор или устройство (`Ctrl+Shift+P` -> "Flutter: Select Device").
  * Запустите приложение одним из способов:
  * Команда в терминале: `flutter run`
  * Кнопка "Play" (`Start Debugging`) над файлом `lib/main.dart`.

# Особенности

  * Использование базовых компоновочных виджетов Flutter.
  * Добавление плавающей кнопки с обработчиком нажатия и выводом сообщения в консоль.
  * Загрузка изображения из сети в виджет `CircleAvatar`.
  * Демонстрация работы с `Expanded` для гибкого распределения пространства.
